# cv-1

Halaman CV/portofolio statis satu halaman untuk Aprilia Dewi Ardiyanti (pengajar dan peneliti fisika). Halaman ini merupakan hasil ekspor statis dari situs WordPress + Elementor.

## Isi Halaman
Profil (pengajar & peneliti), About Me, keahlian, pendidikan, pengalaman, dan kontak.

## Tech Stack
HTML statis dengan CSS/JS hasil ekspor Elementor (termasuk Elementor Pro dan widget tambahan), Font Awesome, eicons.

## Struktur
- `index.html` — halaman utama
- `css/`, `js/`, `fonts/` — aset hasil ekspor
- `images/` — gambar

## Menjalankan
Buka `index.html` di browser atau sajikan dengan server statis (mis. `npx serve .`).
